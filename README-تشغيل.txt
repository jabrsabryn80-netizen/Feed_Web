نظام الحضور والغياب - النسخة الأونلاين
جامعة طيبة التكنولوجية · قسم تصنيع الغذاء

هذه النسخة تستخدم PostgreSQL مستضافة بدل SQLite المحلية، وتدعم مسح QR بكاميرا الهاتف.
تحتاج:
- مستودع GitHub لرفع ملفات المشروع.
- قاعدة PostgreSQL مستضافة (مثل Neon).
- خدمة Node.js مستضافة (مثل Render).

ملفات المشروع:
server.js
package.json
public/index.html

متغيرات البيئة المطلوبة في خدمة الاستضافة:
NODE_ENV=production
JWT_SECRET=ضع هنا مفتاحًا عشوائيًا طويلًا لا يقل عن 32 حرفًا
DATABASE_URL=رابط اتصال PostgreSQL من مزود قاعدة البيانات
DATABASE_SSL=true

مهم:
- لا ترفع ملف .env إلى GitHub.
- لا تشارك DATABASE_URL أو JWT_SECRET مع أي شخص.
- بعد النشر افتح رابط الموقع وأنشئ حساب المدير أول مرة.
- الطلاب ينشئون حساباتهم من واجهة الموقع، والمدير يضيف حسابات المدرسين.
- جلسة QR صلاحيتها 5 دقائق، ولكل طالب تسجيل واحد في الجلسة.
- مسح الكاميرا يحتاج رابط HTTPS واتصال إنترنت.
- النسخة الأوفلاين والمزامنة ستضاف في مرحلة لاحقة.
